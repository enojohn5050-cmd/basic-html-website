# Basic HTML Website

A multi-page HTML only website with semantic structure, SEO meta tags and a contact form.

## Pages
* Homepage
* Projects
* Articles
* Contact

## Technologies Used
* HTML5

## How to Run the Project
1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser
